# Anaplan - Modelling

## Model

Models contain three core types of components,

- Modules
- Line Items
- Dimensions

### Dimensions

- Each module represents a specific function
- Such as margin calculation, employee expense planning, or profit and loss reports
- Use modules to enter data and calculate values.
- Can be categorized using functional Areas
- Module data can be published to dashboards to enable users to understand and work with a model
- Modules can be saved to different data views to enable analysis over different perspectives

### Models

- Use line items to measure data in your model.
- For example profit and loss, revenue, cost of sales, margin, etc

### Line Items

- Use dimensions to form the structure of a module.
- All models include the Time and Versions dimensions along with the organisation and users default list
- Lists can be used as dimensions to group related items in a model
